# Candidate app: screens and behaviour built without a design

Every item below was listed as missing in `docs/MISSING_DESIGNS.md` (C-list and the "new gaps") and was built in the existing
visual style: shared `Dialog` (bottom sheet on phone, dialog on desktop), `Field`, `Button`, `Badge`, the Mwalimu Tools navy
tokens, 44px controls, the focus ring, accessible names, phone-first, no horizontal scroll at 360px, no currency beside a
country name. Backend contract: `docs/API_ADDITIONS.md`. The designer should draw each one.
