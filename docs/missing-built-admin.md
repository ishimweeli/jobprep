# Admin: everything built without a design (MISSING_DESIGNS A-list, E2, E3, E5)

Owner decision (2026-11-04): implement everything listed as missing in the admin area, with no new designs. Each item below was built
in the existing admin visual style (the navy palette and tokens, 44px controls, the focus ring, real modals with labels, a visible
title and Esc, accessible names, desktop tables and phone cards, no sideways scroll at 360px). The designer should draw these; until then
this file is the record of what exists and what was assumed. Item ids are those of `docs/MISSING_DESIGNS.md` (which the lead merges).

Shared parts (new, in `apps/web/src/admin`): `components/AdminDialog.tsx` (modal built on the candidate `Dialog`), `components/ActionDialog.tsx`
(title, consequence, fields, required reason of 5 to 300 characters, error inside the dialog, destructive style), `components/forms.tsx`
(labelled fields with hint and error), `components/Toast.tsx` (a polite status card that goes after 6 s and has Dismiss), `components/ui.tsx`
`Btn` (busy, and `whyDisabled`: a visible control that says why this role cannot use it) and `LinkButton`, `components/states.tsx`
`TableSkeleton`, `EmptyState`, `SaveStatus`, `lib/useUnsavedChanges.tsx` (leave-without-saving dialog and a tab-close warning),
`components/AccessDenied.tsx`, `lib/apiErrors.ts` (plain words for refusals), `lib/permissions.ts` `denyHint`.

## Blocked on the API, or not built
- **Users "Export CSV" (A16, Users page):** blocked on the API. There is no users export endpoint (only payments and the audit log have one). The button is shown disabled with "Not available yet: the server has no users export."
- **Translations of a question (A10):** the API has no endpoint that lists a test's languages other than the mock test's `languages`; tabs follow that list. Nothing else blocked in A10, A11, A15: every endpoint is in `docs/API_ADDITIONS.md`. Built against the contract; the endpoints were not yet in `apps/api` when this was written, so none of it has run against the real API.
- **Delete a mock test (A9):** the API has no delete, only archive (and restore); the form offers Archive and Restore.
- **Topic reorder (A7):** topics have no order in the API (they sort by name); not built.
- **Case-study translations in French (A8):** the API accepts rw, sw and en only, so a test with French has no translation that can be saved for it.
- **Add country, add language, copy structure (A14):** no API endpoint; the buttons stay visible but disabled with the reason.
- **Overview "support requests" row:** still not built, there is no support-request feature or data in the API.
- **Send login code (A5):** does not exist any more (sign-in is password based); "Send password reset" is built instead.
- **Navigation hidden vs disabled (A17):** items a role lacks are hidden, not shown disabled (assumption).
